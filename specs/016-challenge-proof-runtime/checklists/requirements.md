# Specification quality checklist

- [x] Candidate scope and trust inputs are explicit.
- [x] Requirements have testable positive and refusal scenarios.
- [x] Structural, cryptographic, CI and live acceptance are separate.
- [x] Existing authority vocabulary and root-pin rules are preserved.
- [x] Future provider/human/custody gates are explicit exclusions.
- [ ] Owner acceptance of the candidate wire profile and reviewed realization.
